# Security Policy

## Supported Versions

Security fixes are prioritized for the latest release branch and `main`.

## Reporting a Vulnerability

Please do not open public issues for potential vulnerabilities.

Report security concerns privately to `security@ancientice.com` with:

- Affected version or commit SHA
- Reproduction steps or proof of concept
- Impact assessment
- Any proposed mitigation

You can expect:

- Initial acknowledgment within 72 hours
- A triage decision and next-step update after validation
- Coordinated disclosure after a fix is available

## Scope Notes

This project is local-first and may integrate with local devices, smart-home bridges,
and third-party models/services. Treat local config/state artifacts as sensitive and
never publish private credentials.
